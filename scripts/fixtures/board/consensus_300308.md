## 接到期望值框架

拿上面的一致预期直接填三情景（PE 自己按历史分位定）：

```
bear  = 最小值预测 × 偏低 PE     ← 机构里最悲观的那个
base  = 均值预测   × 中枢 PE
bull  = 次年均值   × 中枢 PE     ← 增长兑现一年后
EV = Σ(概率 × 涨跌幅)　；EV ≤ 0 不新增下注，EV > 10% 且确信度高才加仓
```

本股可用:2026 年均值 **339.68** 亿　·　2027 年均值 **670.89** 亿

> ⚠️ **别用网页搜来的单一预测代替一致预期。**2026-08-27 实测 300502:搜到的旧数字(2026E 178 亿 / 2027E 245 亿)算出 EV = −1.1%(边缘),换成 19 家机构真实一致预期(196 亿 / 334 亿)后 EV = **+11.5%**(值得加仓)。同一套框架,数据不全就得出相反结论。
