# 投资思维框架对比 —— 哪种思考方式更可靠

> 2026-08-27。起因：用不同框架分析同一只股票（新易盛 300502），**结论不一样**。
> 这份文档把四种框架摆开对比，用同一组数据各算一遍，看差在哪、该用哪个。

## 一句话结论

**四种框架解决的不是同一个问题，不存在「哪个更好」，但存在「哪个适合你当前的问题」。**

对「已持仓、判断该怎么办」这个问题：
**Mauboussin 的期望值框架最可靠**，我们原有的「领先指标」框架是它的**前置输入**，
两者应该合并 —— 领先指标用来定概率，期望值用来定动作。

---

## 二　同一组数据，四种算法，四个结论

数据：新易盛 300502，现价 409.10，成本 400.00，总股本 13.94 亿股。
2026 中报净利 75.29 亿（同比 +91.0%），券商 2026E 178 亿 / 2027E 245 亿。
四大云厂 Capex 同比 +87% 且在加速。

| 框架 | 怎么算 | 结论 |
|---|---|---|
| **① 纯基本面** | 净利 +91%、毛利率升、ROE 34.9%、PEG 0.42 | **好公司，持有甚至加仓** |
| **② 领先指标**（我们原有） | Capex 加速 + 海外同业背离 33pp + 龙虎榜净买 | **跌的是情绪不是需求，持有** |
| **③ 只算赔率** | 下行 −42.1%（150 亿×22x）/ 上行 +50.4%（245 亿×35x） | **赔率 1:1.2，勉强，不该加仓** |
| **④ 概率加权期望值** | 见下表 | **EV = −1.1%，边缘，不值得新增下注** |

### ④ 的完整计算

| 情景 | 概率 | 净利 | PE | 目标价 | 涨跌 | 对 EV 的贡献 |
|---|---|---|---|---|---|---|
| bear　1.6T 不及预期 / 价格战 | 25% | 150 亿 | 22x | 237 | **−42.1%** | −10.5% |
| base　券商 2026E 兑现 | 50% | 178 亿 | 30x | **383** | **−6.4%** | −3.2% |
| bull　2027E 兑现且景气延续 | 25% | 245 亿 | 35x | 615 | +50.4% | +12.6% |
| | | | | | **EV** | **−1.1%** |

**最刺眼的一行是 base：券商预测完全兑现、给 30x 估值，目标价 383 元，仍低于现价 409。**
也就是说，**当前价已经把 2026 年的好消息 price in 完了，上行必须靠 2027 年。**

### 结论对概率假设有多敏感

| 概率分布（熊/中/牛） | EV | 该做什么 |
|---|---|---|
| 15% / 50% / 35% | **+8.1%** | 值得持有 |
| 25% / 50% / 25% | **−1.1%** | 边缘 |
| 40% / 45% / 15% | **−12.2%** | 该减仓 |

**这才是真正要判断的东西 —— 不是「公司好不好」，是「牛市情景的概率有多大」。**
而领先指标（Capex 加速、海外同业在涨）正是用来**抬高牛市概率**的证据。

> **这就是两个框架该合并的地方**：
> 领先指标不直接给买卖结论，它给的是**概率的修正方向**；
> 期望值框架拿概率算出动作。分开用，两边都会出错。

## 三　四种框架各自是什么

### ① 纯基本面（最常见，也最容易错）

**看什么**：营收/净利同比、毛利率、ROE、PEG。

**为什么会错**：**这些全是已发生的事，股价早已反应。**
「净利 +91% 所以该买」的隐含假设是「市场还不知道」—— 但财报是公开的。

**什么时候有用**：作为**验证层**。当领先指标说需求在改善，
财报确认了利润确实在改善，这个故事才闭上。单独用它不行。

### ② 领先指标（我们原有的 stock-analysis-workflow）

**看什么**：北美云厂 Capex 同比（领先业绩 1–2 季）、海外同业股价、
云厂下季度指引、券商一致预期变动方向。

**强在哪**：**真的前瞻**，而且数据是官方的、可验证的、能定期跟踪。
四大云厂 Capex 从 SEC EDGAR 拿，不是听说，不是研报观点。

**弱在哪**：**只给方向不给幅度。**它能告诉你「需求在加速」，
但不能回答「所以现价贵不贵、该买多少」。
把它当买卖信号用，会在「基本面好但估值已透支」的股票上亏钱。

### ③ Druckenmiller 式：多信号 → 确信度 → 仓位

**来源**：`repos/claude-trading-skills/skills/stanley-druckenmiller-investment/`。

**做法**：把 8 个上游信号（市场宽度、上升趋势、顶部风险、宏观状态、
FTD 底部确认、VCP、主题动量、CANSLIM）合成一个 **0–100 的确信度分数**，
再由确信度决定**仓位配置**。

**强在哪**：**把「多确信」和「下多重的注」连起来了** —— 这是我们完全缺的一环。
Druckenmiller 的实际风格就是：确信度低时几乎空仓，确信度高时重仓押上。

**弱在哪**：它是**市场择时 + 组合配置**导向，需要一整套上游信号 skill 才能跑，
而那些 skill 大多锁在付费 API 上（见 `docs/05-金融skill与SEC库评估.md`）。
对「手上这一只怎么办」这个问题，它太重。

**该借的**：**确信度 → 仓位**这条映射。不该借：整套信号体系。

### ④ Mauboussin 期望值框架（Expectations Investing）

**核心思想**：**不预测未来，先读出价格里已经隐含的预期，再判断公司能否达到。**

三步：
1. **反推**当前价隐含的预期（他用 DCF 反推 sales growth / margins / capital needs
   三个变量；我们简化成 PE 反推净利）
2. 用历史、战略、财务分析判断公司会**超出 / 达到 / 不及**，给三个情景**赋概率**
3. 算**概率加权期望值**，据此决定买/卖/持有

**还有一件我们完全没做的事：基准率（base rates）**。
即：不要只用「这家公司」的内部视角，要用**历史参照类**校准。
例如「净利同比 +91%」，要问的是：
**历史上做到 +90% 增速的公司，四个季度后还能保持 >50% 的比例是多少？**
Mauboussin 的研究显示，**高估值倍数往往先于低于平均的回报**，
因为投资者的预期系统性偏乐观 —— 基准率就是用来对冲这种偏乐观的。

**强在哪**：**唯一一个直接回答「现在这个价该不该买」的框架**，而且逼你
把主观判断显式化成概率，事后可以复核概率给错在哪。

**弱在哪**：概率是主观的。EV 从 +8.1% 到 −12.2% 全看你怎么设概率 ——
**但这不是缺陷，是诚实**。其他框架只是把主观藏起来了。

## 五　我们的方法还缺什么（按价值排序）

### 1　没有「事后复核」—— 最大的漏洞

**现在的流程是单向的：分析 → 给建议 → 结束。**
没有任何机制记录「当时判断了什么、后来对不对、错在哪」。

不复核就不会进步。这一层在同类项目里常见的状态是**有设计没实现** ——
原则库文件建好了，一次没跑过。

**该做**：每次给结论时写下**可证伪的判据 + 当时的概率假设**，
下个季报回来逐条核，记录命中与否。三五次之后就能看出
自己系统性地在哪类判断上过度乐观。

### 2　没有基准率校准

「净利 +91%」听起来很强，但**没有参照系**。
应该用全市场历史数据算：增速 >90% 的公司，N 个季度后还保持 >50% 的比例。

**该做**：`efdata perf` 能拉全市场季度业绩 3885 行，
积累几个季度就能自己算基准率，不用买数据。

### 3　没有「确信度 → 仓位」的映射

现在给的是「持有/减仓/清仓」的离散动作，
但**没回答「持有多少」**。Druckenmiller 式的确信度分数正是补这个。

**该做**：把领先指标的状态映射成 0–100 确信度，
确信度 × EV 决定仓位上限。

### 4　只算赔率不算期望值

已经在本文档修正 —— **要把三情景概率显式写出来并算 EV**，
不能只报赔率。赔率 1:1.2 看着还行，EV 却是 −1.1%。

### 5　PE 反推太粗，应该向 DCF 反推靠

PE 是「增速 + 利润率 + 资本效率 + 折现率」的混合体，
反推出来只有一个数（隐含净利），无法定位**是哪个假设太乐观**。
DCF 反推能拆出三个独立变量。

**该做**：先做个折中版 —— 反推出「隐含的收入增速」和「隐含的净利率」两个变量，
比单一 PE 有信息量，又不用完整 DCF。

## 六　所以该用哪个：合成后的流程

```
① 领先指标定方向     Capex / 海外同业 / 指引 / 一致预期变动
        ↓            输出:需求在改善还是恶化(不给买卖结论)
② 基准率校准         历史上这种增速能持续多久
        ↓            输出:对乐观情景打折
③ 反推市场预期       市值反推隐含净利/增速 → 市场在担心什么
        ↓            输出:预期差在哪、已被①证否了没有
④ 三情景赋概率       bear/base/bull,概率由①②③共同决定
        ↓
⑤ 算期望值 EV        EV ≤ 0 不新增下注;EV > 10% 且确信度高才加仓
        ↓
⑥ 确信度定仓位       确信度低 → 小仓;高 → 可重仓
        ↓
⑦ 写下可证伪判据     下个季报回来逐条核,记录对错
```

**①②③ 是输入，④⑤ 是决策，⑥ 是执行，⑦ 是学习。**
现在我们有 ①③④(部分)，缺 ②⑤⑥⑦。

## 七　用合成流程重做 300502 的结论

**① 领先指标**：Capex 同比 +65%→+87% 加速；海外同业近 1 月 +13.9% vs 本股 −18.8%；
北向成交占比 12%→17%。**方向：需求在改善。**

**② 基准率**：缺（未实现）。**保守处理：把 bull 情景概率打折。**

**③ 市场预期**：当前市值隐含 2026 净利约 150 亿（38x 口径）。
市场担心「AI Capex 见顶」——**这条已被 SEC 官方数据证否**。预期差成立。

**④ 概率**：领先指标向上支持提高 bull 概率，但基准率缺失要打折，
筹码分散（股东户数 +65.3%）和融资余额 195 亿压制短期。
**取 熊 25% / 中 50% / 牛 25%。**

**⑤ EV = −1.1%** —— 边缘。**不值得新增下注。**

**⑥ 仓位**：确信度中等（领先指标向上但筹码差、缺基准率校准）→
**维持现有仓位，不加不减。**

**⑦ 判据（下个季报核）**：
- Capex 同比仍 > 50% → bull 概率上调到 35%，EV 转正 +8.1%，**那时才值得加仓**
- Capex 同比掉到 < 20% → 预期差消失，**清仓**
- 净利同比 < 30% 或毛利率 < 43.4% → base 情景下移，**减仓一半**

**与之前结论的差别**：之前说「继续持有」，方向没变，
但**多了一个明确的加仓条件（Capex 同比仍 >50%）和一个量化的当前判断（EV −1.1%，不加仓）**。
之前的「347–380 补仓」是基于技术位，现在有了更硬的依据 ——
**在 383（base 目标价）以下买，才是在为 2026 年的确定性付合理的钱。**
