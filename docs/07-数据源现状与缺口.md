# 数据源可达性探针

> **这是一份示例输出**，来自某台受限网络机器上的一次实测（2026-08-27）。
> 数据源可达性**因网络环境而异** —— 你自己跑 `probe_sources` 会得到你自己的结果，
> 以你的为准。放这份进来是为了让你在跑之前就知道**输出长什么样、有哪几类结论**。

## 二　明确拿不到的（附原因、试过什么、替代）

**这一节是本脚本最重要的部分。**下次别再从头搜一遍，也别误以为是接口坏了去修。

### 北向资金**净买方向**（个股级）

- **为什么拿不到**：监管 2024-05-13 停日内实时、**2024-08-19 停日终数据改按季公布**。不是接口坏了，是不再披露。
- **试过**：akshare 全部 hsgt 接口（`individual_em` 数据停在 2024-08-16）· adata（无北向模块）· 东财 RPT_MUTUAL_TOP10DEAL 的 `NET_BUY_AMT` 字段为 None · 港交所 CCASS（那是港股持股，A 股北向在中登）
- **替代**：**深股通/沪股通前十大成交活跃股**仍每日公布 —— 拿得到**成交额与占该股总成交比例（参与度）**，拿不到方向。另有季度持股与季报十大流通股东里的「香港中央结算」（滞后最长 5 个月）。
- 相关端点当前状态：`https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_MU` → **200**

### 微软 / 亚马逊的 **Capex 指引**

- **为什么拿不到**：这两家在**电话会口头给**指引，不写进 8-K 新闻稿；电话会纪要不属于 SEC 披露文件。
- **试过**：SEC 8-K 的 EX-99.1 全文正则扫（谷歌、Meta 命中，这两家零命中）
- **替代**：谷歌、Meta 的指引拿得到（`capex --guidance`）。微软/亚马逊要靠 transcript：Motley Fool / Seeking Alpha 页面可达但是 JS 渲染的 Next.js payload，需要浏览器渲染才能取；EarningsCall / Alpha Vantage 有 API 但要 key。
- 相关端点当前状态：`https://www.fool.com/earnings-call-transcripts/` → **200**

### **产业高频数据**（1.6T 月度出货量 / 800G 报价 / 光芯片供需）

- **为什么拿不到**：不在任何免费公开源。券商产业链调研报告与 LightCounting 等第三方咨询机构的付费数据库才有。
- **试过**：akshare（只有宏观进出口总额，无 HS 编码细分）· 海关总署 stats.customs.gov.cn（**412，WAF 挡爬虫**）· 国贸通 gtradedata.com（页面可达但**数据在付费报告里**）
- **替代**：**海关月度出口是个可行方向但目前取不到**：HS 编码 **85177060 = 光通信设备的激光收发模块**，月度出口额公开发布，财经媒体会转载具体数字。可靠的自动化路径需要突破海关网站的 WAF，或找已经整理好的第三方免费源。**目前只能靠 WebSearch 读新闻里的数字。**
- 相关端点当前状态：`http://stats.customs.gov.cn/` → **412**
