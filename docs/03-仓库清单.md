# 03 · 仓库清单(repos/)

6 个开源股票分析仓,均为真 git 仓(https origin,自己终端可 `git pull`)。
完整横向对照与选型见 `docs/A股择时工具选型.md`;这里只做一句话速查。

| 仓 | 是什么 | 路线 | A股/东财 | 对「按成本给择时」的适配 |
|---|---|---|---|---|
| **AI_Investment_Manager** | 持仓管理 + LLM 建议(网页) | LLM 单轮 | ✅ 新浪腾讯为主 | **最对口**:吃持仓成本、给长短线+目标价+止损+行动计划;轻量好跑 |
| **a-stock-data** | A股数据源大全(54端点/19源) | 数据工具(Skill) | ✅ 含东财 | 不做分析,是**取数底座**;已装成 skill |
| TradingAgents-CN | 多智能体 LLM 投研(31k★) | LLM 多Agent辩论 | ⚠️ 默认东财(这台受限机器需换tushare;网络不受限时可用) | 分析深,但不吃持仓成本、不给长短线 |
| KHunter | 规则量化 + 回测 | 纯规则 | ✅ 腾讯/TickFlow | 全市场选股+回测;不吃成本、无LLM;回测是独门 |
| daily_stock_analysis | LLM 多市场分析 + 推送 | LLM | 待核 | 零成本定时运行、决策看板;未精读 |
| tick-stock-panel | A股选股+监控+回测工作台 | 规则+LLM | ✅ TickFlow | 自托管量化工作台;未精读 |

## 选型结论(摘要)

- **要「按持仓成本给某只票长短线+扛还是割」** → 首选 `AI_Investment_Manager`。
- **要取更全的数据(龙虎榜/资金流/研报/估值分位)** → 用 `a-stock-data` skill,**东财可达时能发挥全部端点**。
- **要历史回测证据** → `KHunter`。
- **要最深的多智能体分析** → `TradingAgents-CN`(东财可达时数据源不用改)。

## 跑起来要什么

- 多数需一个 **LLM key**(DeepSeek 最省;或改走 `claude -p` 订阅)。行情数据不要 key。
- 详细部署见各仓自己的 README + `docs/A股择时工具选型.md` 的「落地方案」。
